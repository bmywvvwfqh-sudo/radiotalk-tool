# 放射科語音指揮工具

語音辨識輔助工具，幫助放射科醫療人員快速下達指令。

## 功能
- 語音識別
- 實時指令執行
- 離線使用支援（PWA）

## 技術
- HTML5 + CSS3
- Vanilla JavaScript
- Service Worker（離線支援）
- Web Speech API

## 開發
```bash
npm install  # 如果需要
# 直接用任何 HTTP server 打開
python3 -m http.server 8000
```

打開 `http://localhost:8000`

## 部署
- 支援靜態網頁部署（GitHub Pages、Vercel 等）
- PWA 支援（可安裝到主螢幕）
